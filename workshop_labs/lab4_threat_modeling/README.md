# Lab 4: Threat Modeling an Agentic RAG App (20 min)

## Goal
In pairs (12 min exercise + 8 min group debrief):
1. Review `architecture.md` (an internal Slack assistant with Confluence RAG + Jira/Email write tools).
2. Identify **all untrusted data sources** and **privileged sinks**.
3. Fill out `threat_model_template.md` with **3 concrete attack paths**, mapping each to the OWASP LLM Top 10 and the "Lethal Trifecta", and propose a concrete architectural mitigation.
