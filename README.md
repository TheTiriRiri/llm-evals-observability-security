# Production AI Engineering: Evals, Observability & Security

Materials for a 2 × 3.5 h hands-on workshop.

| File / directory | What it is |
| :--- | :--- |
| [curriculum.md](./curriculum.md) | Schedule, learning objectives per unit, Production Readiness Checklist |
| [slides_and_facilitator_notes.md](./slides_and_facilitator_notes.md) | Slide outline and facilitator notes |
| [workshop_labs/](./workshop_labs/README.md) | Six labs (Python 3.11+, promptfoo, Langfuse, Presidio) plus reference solutions |
| [appendix_take_home.md](./appendix_take_home.md) | Take-home appendix, state as of November 2026: agent evals, injection-resistant design, MCP security, GDPR, AI Act, the 2026 tool landscape, home exercises |

The curriculum, the slides, the appendix and the lab instructions also have Polish versions with the `-pl.md` suffix, e.g. [appendix_take_home-pl.md](./appendix_take_home-pl.md). Worksheets, payloads and solutions are in English only.

Participant setup: see [workshop_labs/README.md](./workshop_labs/README.md) and run `python check_env.py` in `workshop_labs/`.
